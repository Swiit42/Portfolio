# 🌐 Portfolio - Oleksandr Tymoshenko

Bienvenue sur mon portfolio en ligne, développé avec **Vue.js 3**, **Vue Router** et **Tailwind CSS**. Ce site présente plusieurs de mes projets en développement web, data engineering et visualisation, avec des cas concrets, du code, et des captures illustratives.

## 🚀 Objectifs

- Présenter mes projets personnels et professionnels (CryptoTrade, BankingApp, dashboards Power BI…)
- Démontrer mes compétences techniques en développement, cloud et data
- Permettre un contact facile pour des opportunités professionnelles

## 🛠️ Stack technique

- **Vue 3** (Composition API)
- **Vue Router**
- **Tailwind CSS**
- **EmailJS** (formulaire de contact)
- **Déploiement :** GitHub Page
